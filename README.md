# 鹈鹕骑行 · 海滨晨风

**在线地址：https://yjj0339.github.io/pelican-cruise/**

手机扫码直达：`qr-live.png`　·　所有作品入口：https://yjj0339.github.io/

一只鹈鹕骑着一辆青绿色单车沿着海滨小路往前赶的 2D 动画，纯手写 Canvas 绘制，零外部资源、零依赖，单文件 `index.html`。

## 画面内容

- **主角**：白羽鹈鹕，长喙 + 会晃动的喉囊、黄眼睛、珊瑚色围巾随速度飘动；双翼随节奏轻扇。
- **踏频**：双脚用两骨 IK 实时解算，始终踩在曲柄踏板上；车轮按滚动摩擦角 `距离/半径` 转动，齿比 2.35，所以轮子比脚转得快——是真的在骑，不是在滑。
- **场景**：六层视差——云 / 海面波光与帆船 / 远山 / 树线 / 路肩灌木 / 沙石小路 / 前景草叶野花，层层不同速度向后退。
- **细节**：后轮扬起的沙尘、车铃偶尔"叮铃"一声、加速时的速度线、设备像素比自适应（手机上不糊）。

## 操作

| 操作 | 效果 |
| --- | --- |
| 点击 / 轻触画面、空格、回车 | 鹈鹕整车跃起一下（带翅膀扇动） |
| 暂停 / 播放按钮、`P` 键 | 定格 / 继续 |
| 速度滑杆 | 0.3× ~ 2× 骑行速度 |

系统开启"减弱动态效果"时默认暂停。

## 技术

单个 `index.html`（约 37 KB），无构建、无依赖、无网络请求，直接双击打开或用任意静态服务器托管即可。所有图案均由 Canvas 路径手绘，景物用确定性随机数播种，每帧只做视差循环，不重复生成。

本地预览：

```bash
npx --yes serve .
# 或
python -m http.server 8080
```
